# Accessibility summary

Representative Axe coverage includes Library, Gallery, Builder, Studio, Launch, Live, Arabic Studio, and centered dialogs. Final merchant coverage reports zero critical and zero serious violations. The W4 operations accessibility project also passes in English and Arabic/permission-denial states.

Verified behaviors include landmarks, heading order, explicit labels, visible focus, keyboard traversal, real tab semantics, dialog focus trap/restoration, Escape/backdrop rules, busy-state dismissal lock, status announcements, non-color status cues, named icon controls, minimum mobile targets, and RTL focus order.

Studio routed navigation restores focus to the newly selected content area. The W4 accessibility test selects an available customer row semantically rather than depending on a mutable fixture display name.
