# Flutter handoff

M1-M4 receives `provider-artifacts/openapi.json`, `flutter-contract.json`,
`stable-fixtures.json`, `packages/contracts/src/w4.ts`, and
`@waflo/staff-device-security`. The mobile private key must remain in platform secure storage.
Retries reuse the operation idempotency UUID but create a new nonce/timestamp.

No Flutter or native mobile source is included.
