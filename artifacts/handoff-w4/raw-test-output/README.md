# Raw test output

This directory contains final command transcripts and exit-code summaries. It contains no runtime
secrets, QR payloads, device sessions, customer emails or generated PII exports.

Use `quality-gate-summary.json` for the machine-readable core gate, `BROWSER-EXIT-CODES.md` for
cross-phase browser evidence, `archive-extraction.log` for the clean portable-source verification,
and `process-cleanup.log` for the final managed-port state.
