# Production-v1 interface localization

KURDISH_NATIVE_REVIEW_REQUIRED=YES

The interface locale registry keeps Kurdish Badini (`ku-badini`) and Kurdish Sorani
(`ku-sorani`) as separate right-to-left interface locales. It deliberately does not
expand the existing `en`/`ar` customer-content, Wallet, or mobile API locale contract.

Before release, a native Iraqi-Kurdistan linguistic review is required for every
customer-facing and merchant-facing string migrated into the centralized locale files.
