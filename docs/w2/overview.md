# Waflo W2 overview

W2 adds the merchant-facing Loyalty Studio for the `STAMP` program type. It owns program economics, localized content, visual themes, validation, synthetic Test Mode, and publication. Customer, Membership, Wallet issuance, staff scanning, QR, and Flutter remain deferred to W3.

The API is organization-scoped through the existing TenantService and audit boundary. The dashboard uses the existing merchant shell and Waflo brand tokens.
