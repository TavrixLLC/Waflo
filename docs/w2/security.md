# W2 security

Every program, version, asset, preview, validation run, test session, and publish command carries an organization ID and is reached through a tenant-scoped query. Programs use centralized role permissions. Uploads reject executable/image formats outside the allowlist, external fetching, unsafe filenames, and signature mismatches. Published versions are immutable through supported services. Audits record creation, edits, validation, Test Mode, asset upload, state changes, and publication.
