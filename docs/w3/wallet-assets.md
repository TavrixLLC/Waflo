# Wallet assets

Wallet images are derived from approved W2 Program Version assets and themes. The renderer preserves the exact filled/empty stamp states and never substitutes stars, gifts, numbers, check marks, badges, or milestones in the main grid.

Generated progress assets are immutable by public random token and projection version. The public endpoint returns only image bytes and safe cache headers; tokens are unrelated to customer, Membership, credential, or contact identifiers.

Assets are stored through the W2 object-storage abstraction. Google references the public immutable URL. Apple embeds the prepared raster assets in the signed package.

Private originals, raw provider payloads, and customer data are never exposed by the public asset endpoint.
