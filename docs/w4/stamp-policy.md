# Stamp policy

Issuance evaluates the Membership's pinned Program Version, Organization and billing state,
Membership and credential state, Program status, participating Location, Staff assignment and
device assignment.

Policy fields include operational timezone, maximum stamps per operation, optional gross daily
cap, and optional minimum purchase in integer minor units with exact ISO currency. The daily cap
counts gross positive stamps; a reversal does not restore allowance. A permitted manager override
requires an approved challenge, a reason, audit metadata and a risk signal.

No floats, currency conversion, payment-card data, receipt image, or arbitrary Location ID enter
the transaction.
