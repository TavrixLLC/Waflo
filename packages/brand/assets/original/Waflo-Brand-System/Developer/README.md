# Waflo developer handoff

## Use the logo

- Light surfaces: `Logo/SVG/waflo-logo-primary-horizontal.svg`
- Dark surfaces: `Logo/SVG/waflo-logo-white-horizontal.svg`
- App and compact UI: `Logo/SVG/waflo-mark-primary.svg`
- Favicon: `Web/favicon.svg` with PNG/ICO fallbacks

## UI defaults

- App background: Cloud `#F7F9FF`
- Surface/card: White `#FFFFFF`
- Primary CTA: Waflo Brick `#AE3115`
- CTA hover/pressed: Ember `#7D2311`
- Accent/highlight: Flow Coral `#FF6B4A`
- Primary text: Warm Ink `#241916`
- Default card radius: 22px

## Typography

- Latin: Manrope
- Arabic: Noto Sans Arabic
- Recommended weights: 400, 500, 600, 700, 800
- Keep Arabic layouts RTL and use Arabic numerals according to product locale settings.

## Accessibility

- Use white text on Waflo Brick or Warm Ink.
- Use Warm Ink text on Flow Coral, Soft Coral, Cloud, or White.
- Do not use white body text directly on Flow Coral.
